# Projects_1st-Year
This is a project developed by using Scratch, a visual based programming language to create games and animations.

The name of the game created by me is - **The Ghost Mansion**.

The link to the same is : https://scratch.mit.edu/projects/1438022411

How to play?
*   **Controls:** Use your mouse or fingers to control the red sprite, **Giga**. 
*   **Objective:** Giga has to touch the ghost sprite (blue in colour).
*   **Scoring Points:** Your each successful touch gives you **1 point**. 
*   **The Penalty:** But make sure, that if you touch or get touched by the yellow sprite, **Gobo**, you lose **2 points**.
*   **Time Limit:** There is a timer of **30 seconds**, after which your final score gets displayed on the screen.

Learnings from the project:-
*  **Collision Detection:** Setting up real-time conditional checks to differentiate between standard point-scoring targets (the blue ghost) and obstacle hazards (Gobo).
*   **Variable Manipulation:** Managing interactive score structures dynamically using standard addition and deduction logic.
*   **Concurrency & Timeouts:** Running an independent clock cycle loop in parallel with user input threads to end active gameplay at exactly 30 seconds.
